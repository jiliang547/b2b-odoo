# Partner Hub 多语种验证记录

日期：2026-09-11。本地 Odoo 19，数据库 b2b_v41_test_20260817，网站端口 8070；未验证 Odoo.sh 部署环境。

## 实现范围

- 使用 Odoo 原生 PO、QWeb、JavaScript `_t` 和可翻译字段，无在线翻译服务，无多套页面。
- 英文基础文案，西班牙语、法语、阿拉伯语共 5244 条已填译文。自定义内容用 AI 翻译；能匹配的原生文案复用原生译文。
- 新注册客户保存注册语言；验证、批准、拒绝邮件按客户语言发送。
- 保留非中文网站默认语言设置；注册国家名称按既有要求保持英文。

## 自动化结果

- `scripts/validate_source.py`：6 个模块、86 个 Python 文件、50 个 XML 文件通过。
- `scripts/validate_translations.py`：5244 条译文通过占位符、HTML 结构及导出目录中客户侧词条覆盖检查。
- `TestPartnerHubMultilingual`：5 项通过，0 failed、0 errors。
- 覆盖三种语言的产品、注册、隐私页共 9 个 HTTP 页面，原生前端 JS 翻译目录、字段翻译与英文回退、切换语言不改变联系人价格表、保留运营默认语言、验证邮件按客户法语渲染。
- 初次测试误用了不存在的 website.pricelist_id 字段，修正为联系人原生 property_product_pricelist 后重跑通过，没有跳过断言。

## 真实浏览器点击

- 首页打开语言菜单 → Español：首页标题、按钮及导航切换为西班牙语。
- 点击产品入口：进入西班牙语产品页，语言保留、币种仍为 USD。
- 产品页切换 Français：产品目录及筛选控件显示法语，币种不变。
- 切换 العربية 并打开注册页：字段标题、协议、提交按钮显示阿拉伯语。
- 填入测试密码并点击眼睛：密码输入类型变为 text；点击空表单提交：出现阿拉伯语必填提示，未发送注册申请。
- 阿拉伯语页面截图和 DOM 验证：正文 rtl、两个电话输入组合及号码 ltr、无当前桌面视口水平溢出。

## 实测发现与处理

1. 本地缺少 rtlcss，Odoo 回退到未镜像 CSS：已安装原生所需工具、清理一份可重新生成的 RTL 缓存资源并重建。
2. 电话方向保护最初使用的注释未传递给 RTL 编译器：改为保留的原生 RTL 指令，并对电话组合控件保留 LTR 排版。

## 边界

- 以上不是全站全流程回归，不代表已重测支付、ERP、全部售后或订单修改场景；本次没有真实支付和真实邮件投递。
- 运营在数据库自行创建的产品、分类、品牌等内容不会因为安装语言而自动生成译文；浏览器中现有未翻译的商品和分类仍回退英文，需按维护手册在同一条记录补充翻译。
- 本次桌面浏览器复核不替代全部手机尺寸测试；新增语言和 Odoo.sh 上线后应按操作手册清单复核。
- AI 法律条款译文建议后续人工复核。本次未推送 GitHub。
