# 客户品牌自动归属：操作与验收

更新：2026-09-15。多公司扩展版本：19.0.1.3.0。

## 1. 日常怎么操作

五家销售公司保留各自账套。运营给客户公司设置品牌，日常勾选全部获授权销售公司，后续尽量从客户或已有单据进入操作，不必每做一张订单就切换右上角当前公司。

首次仍需完成 Business Setup、品牌法人和银行、客户价格表、付款条款及员工公司权限。全选不是新增权限，也不等于合并会计账套。当前使用 External ERP，不要求建立工厂角色；API 对接另行验收。

### 客户分配

1. Contacts → 打开客户的公司记录，不是其下个人联系人。
2. Partner Hub → Collection and Brand → 选择 Account Brand。
3. Assigned Selling Company 自动带入品牌对应法人，核对后保存；Collection Terms 仍按客户约定填写。
4. 个人联系人继承商业主体归属。不要把原生联系人 Company 字段当成品牌分配入口。

品牌必须配置销售法人。不能分配本人无权操作的公司，也不能将有待处理提交报价的客户直接转给另一销售法人。原有单据不会随客户改品牌而重写。

### 后台新报价

1. 右上角勾选所需销售公司并 Confirm，可以保持 A 为当前公司。
2. Sales → Orders → Quotations → New。若 Sales 默认已在报价列表，直接 New。
3. **先选 Customer，后加产品**。选择 B 品牌客户，系统取 B 销售公司。
4. Partner Hub Website 在唯一匹配时自动带入；有多个网站时先明确选择。客户有效价格表按客户商业主体和网站筛选，不能使用另一客户的专属价。
5. 添加商品、数量，核对金额、税费和币种，再点击上方 Save manually 云形保存按钮。
6. Collections & PI 核对品牌、付款条款、银行与当前应付；Fulfilment 核对 External ERP。保存只创建报价及收款配置，不等于已收款或确认销售订单。
7. 后续修改数量／价格、发送给客户、收款及改单继续走原有流程。已保存的客户优先报价不允许换成另一客户公司的报价，应新建，防止混用原收款说明。

缺少有效价格表、网站不明确或公司未勾选时，先按提示补配置，不要通过改原生 Company、乱选价格表规避检查。无品牌普通客户及未标记的原生程序创建／导入保留原有行为；本次不是对所有 API 入口强制重新分配公司。

### 发票、收款与退款

| 入口 | 公司来源 | 还需核对 |
| --- | --- | --- |
| 销售订单 → 创建发票 | 原销售订单 | 发票金额、税费、币种与账户 |
| 发票登记收款／凭证打开原生收款 | 原来源单据 | 实际到账及过账、核销 |
| Accounting → Customers → Invoices → New | 新空白表单先选客户时建议其销售公司和销售日记账 | Other Info → Company；币种和会计资料，不自动当成网站报价 |
| Accounting → Customers → Payments → New → Receive | 先选客户建议其销售公司；唯一匹配币种银行时建议该银行 | Journal、Company Bank Account、Currency、实际到账 |
| 改单申请 → Register / Open Bank Refund | 原订单公司及银行上下文 | 真实退款、原生记录过账、返回关联 Bank Refund Payment |
| 原生日记账配置／历史补录／供应商付款 | 原生公司或明确指定的上下文 | 目标法人，不能凭客户当前品牌迁移历史账务 |

独立发票应先选客户再添明细。已有明细、已保存记录、退款、明确指定公司或日记账的来源，不强行覆盖。一个品牌有多个匹配收款账户时，不代财务猜测实际银行。银行名称建议包含品牌和币种；原生表单不一定直接展示 Company，可进一步核对关联日记账。

退款按钮只在待财务审核的银行退款申请中显示。点击打开原生付款表单，不发起银行转账。登记真实退款后返回申请，在 Bank Refund Payment 中选中退款记录，再完成财务审核。已关联记录则打开原记录，避免重复新建。

## 2. 实现范围与维护原则

- 复用 res.partner、sale.order、account.move、account.payment 和原生表单 onchange，不另建账套或付款模型。
- 品牌分配同步销售法人；权限和公司隔离仍使用原生规则。
- 新后台报价用来源标记区分客户优先表单与原生内部供货、复制提案、导入等流程，避免全局拦截破坏旧业务。
- 原单公司优先于客户后来改过的配置。保存报价同时初始化现有 Collections & PI，不重写历史银行快照。
- 独立会计表单仅建议默认值，不强制将历史财务数据改成当前客户归属；不自动确认收退款。
