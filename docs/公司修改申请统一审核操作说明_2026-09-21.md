# 公司修改申请统一审核

## 运营入口

打开 B2B Management → Dashboard → **Pending company changes**。
此处统计所有 New / In Progress 的公司修改申请，不受右上角勾选哪家销售公司影响。
点击卡片直接进入待处理申请列表。其他类型的 Contact Request 不计入该卡片。

打开申请，查看 Requested Company Data 和客户描述。运营可 Start 接手、回复、补充资料；B2B Manager 核实并通过既有客户资料页面完成实际修改后，再 Resolve。无需继续处理的申请由 Manager Close。
Resolve 是结束审核，不会自动把申请里的公司名称覆盖到客户资料，也不会自动更换销售公司或品牌。

共享的是申请和申请对话，不是客户、订单或财务资料。实际修改客户时，仍须具备对应权限及公司访问权。

## 两种数字含义

- **Pending company changes**：待处理事项总数。阅读或回复不会消除；Resolve / Close 后减数。
- **Unread messages**：当前员工自己的未读会话数。新公司修改申请通知负责人；其他员工不会因为能查看申请而自动收到相同未读通知。打开会话标记已读后数字减少，不影响待处理数。

负责人沿用现有网站销售员/运营回退分配规则及原生待办。公司修改申请对话不再因公司切换隐藏；订单及其他公司的业务对话继续按原有公司权限筛选。客户仍只能查看原有权限范围内的申请。

Dashboard 打开时刷新，并在前台每 60 秒及窗口重新获得焦点时刷新；统计失败显示“—”，不伪装成 0。

## 升级说明

更新 b2b_website、b2b_management。旧公司修改申请对话自动调整为共享，不重发历史邮件、不更改历史已读状态。历史未完成申请直接纳入待处理数量。
