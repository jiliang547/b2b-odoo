# 注册关联已有公司：原生消息兼容修复

## 原因及处理

注册申请曾以 `company_id` 关联客户档案 `res.partner`，与原生邮件机制将其视为 `res.company` 的约定冲突。关联客户后，审批/拒绝完成待办或发送消息可能错误查询同编号的销售公司；编号碰巧存在也可能导致错误邮件归属。

现改为 `resolved_partner_id`，界面仍显示 Resolved Company，不改变运营选择方式。复用原生 `_mail_get_companies` 扩展方法：多公司模块优先使用所选客户的销售公司，无配置时使用网站公司，再回退当前环境公司。不修改 Odoo 原生代码，不移除待办或跳过消息记录。

## 升级与数据

网站模块版本 `19.0.1.16.25` 的预迁移重命名数据库字段，保留原有客户关联及字段元数据ID（包括历史跟踪记录）；同步更新注册模型的视图引用。新安装直接使用新字段。若发现新旧列同时存在，停止迁移而非猜测覆盖。

升级需更新 b2b_website、b2b_multicompany、b2b_yonyou。自建外部程序若直接读写注册申请的 `company_id`，需要改用 `resolved_partner_id`；原生订单、会计等模型的 `company_id` 不变。
