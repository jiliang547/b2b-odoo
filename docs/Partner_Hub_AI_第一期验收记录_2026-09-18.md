## 追加验收：随主项目自动安装与只配置 Key

### 实现

- `b2b_management` 版本提升至 `19.0.1.10.0`，显式依赖 `b2b_ai`；AI 声明 `auto_install=['b2b_multicompany']`，复用原生依赖安装，不编写启动时强行安装应用的代码。

### 浏览器复核与发现的问题

使用隔离 8072 的普通 Settings 管理员（非超级用户、不含 B2B Integration Manager）实际点击：应用入口 → 网站列表 → 网站配置 → Native AI Settings → 勾选自己的 ChatGPT account → 输入非真实测试字符串 → Save。

首次保存复现 ERP 密钥字段 Access Error。根因是原生 Settings 保存会遍历全部 config_parameter 字段，而 ERP Key 限制给 Integration Manager，即使隐藏也会被读取。已在 ERP 扩展中过滤无该角色的配置保存项，未放宽密钥读取/写入权限；保存其他设置也不会清空原 ERP Key。修复后原生 Save 成功，没有权限弹窗。该兼容修复不依赖 AI 模块。

同时修正新授权按钮的字段/按钮权限声明不一致警告。最终升级日志不再出现该视图警告。

保存非真实测试 Key 后，前台准备中提示消失、Send question 自动可用，无需另选 Agent 或勾选测试开关。本次不点击发送、不对外调用；验证结束清空测试 Key，恢复未配置状态。
