# 付款前改单操作手册

适用版本：19.0.1.15.2；更新日期：2026-09-11。

## 1. 什么时候使用

客户尚未付款，希望运营人员先调整商品、数量、单价或运费，再确认最终金额并付款。

客户不是必须走审核：不需要调整时仍可直接 Pay now。需要调整时选择 Submit for Review — Pay Later。此流程直接维护同一张原生报价单，不创建付款后使用的 Order Change Request。

## 2. 客户：先下单、不付款

1. 登录获准下单的客户账号，将商品加入购物车。
2. 进入购物车，确认商品和数量，点击 **Checkout**。
3. 检查收货地址、账单地址及配送方式，点击 **Confirm**，进入付款页面。
4. 在 **Need us to adjust the order first?** 区域点击 **Submit for Review — Pay Later**。不要点击旁边的 Pay now。
5. 页面进入订单详情，显示订单编号及 **Review in progress**。记下订单编号。
6. 如需补充修改要求，在订单底部 Communication history 发送消息，写清商品、数量、价格或运费需求，也可通过现有客服联系渠道说明。

审核中不会显示支付或签名入口；旧支付窗口或直接交易请求也不能跳过审核。该订单可从 My → Orders 找回。

## 3. 运营：修改并放行

要求：B2B Manager，并具有编辑相应原生销售单据的权限。

1. 后台 **B2B Management → Operations → Orders Pending Review**，或点击 Dashboard 上的 **Orders pending review** 卡片。
2. 找到客户提供的订单编号并打开。
3. 在 **Order Lines** 点击需要修改的行：
   - 修改 **Quantity**：数量。
   - 修改 **Unit Price**：单价。
   - 点击 **Add a product** 增加商品；行末垃圾桶删除不需要的商品。
   - 调整已有配送行的费用，或按业务要求使用原生运费功能。避免重复增加两条同类运费。
   - 检查税率、折扣、未税金额和含税总金额，不能只看单价。
4. 点击页面顶部订单编号旁的云朵向上箭头，鼠标提示是 **Save manually**。这是原生整页表单的保存按钮；有未保存修改时才显示。
5. 保存后检查最终总额，再点击顶部 **Release for Customer Payment**。
6. 不要把 **Confirm**、**Send** 或手工改状态当作放行按钮。等待审核的订单必须先放行。

放行后订单仍等待客户付款，不代表已经收款。审核状态变为 Ready for Payment；订单记录会写入放行消息。邮件是否实际送达还取决于发信配置，不能仅凭消息记录认定客户收到邮件。

## 4. 客户：确认最终金额并付款

1. 回到 **My → Orders**，打开同一个订单；已打开的页面先刷新。
2. 确认显示 **Ready for payment**，逐项核对商品、数量、价格、运费和含税总额。
3. 点击 **Accept & Pay**；如果已完成签署，按钮名称可能为 Pay Now。
4. 在 **Pay Order** 窗口选择支付方式，完成必要信息，点击 **Pay**。
5. 等待支付结果和页面跳转，处理中不要重复提交。
6. 成功后显示付款成功、订单成为 Sales Order，订单编号保持不变。

如果支付失败或取消，先查看原订单和支付状态，再重试；不要另建重复订单。支付 Pending 时应等待支付服务商结果，不应继续修改正在付款的订单。

## 5. 已实测案例

测试订单 **S00547**：客户通过商品页面、购物车、地址页实际点击提交审核。

| 项目 | 审核前 | 审核后 |
| --- | --- | --- |
| 商品数量 | 2 | 3 |
| 单价 | $12.00 | $10.00 |
| 运费 | $0.00 | $5.00 |
| 税率 | 15% | 15% |
| 含税总额 | $27.60 | $40.25 |

运营实际点击 Save manually 和 Release for Customer Payment；客户刷新后核对 $40.25，使用 Demo 点击 Pay，交易成功，订单编号仍为 S00547。之后此测试订单又用于退款改单测试，现有最终金额不是本节的付款时金额。

## 6. 注意事项

- 本手册对应“客户主动选择先审核再付款”。已经付款、授权扣款或支付处理中的订单，不能当作普通未付款报价单随意改价。
- 完成付款后如需再次修改，使用《付款后改单操作手册》，不要直接改已付款原订单绕过申请。
- Demo 只模拟流程，不会实际收款；正式支付配置和银行到账应另行核对。
- 本次验证环境是本地 8070，不代表已经部署或验收 Odoo.sh。
